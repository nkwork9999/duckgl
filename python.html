Python 組み込み API

アプリが用意した DuckDB 接続に、型付きの引数を渡して利用します。

Python ソースを表示

PublishedLayer

Publish a host-selected main-schema relation for the lifetime of a with block.

  • __init__(self, connection: DuckDBPyConnection, view: str)

Viewport

  • west: float
  • south: float
  • east: float
  • north: float

MapPoint

  • feature_id: int
  • longitude: float
  • latitude: float
  • label: str | None

GridCell

  • x: int
  • y: int
  • count: int
  • longitude: float
  • latitude: float

PointLayer

Read WGS84 points from a trusted host-selected main-schema relation. The host provisions a tenant-scoped connection and a primary/unique feature_id. Longitudes in the source use the [-180, 180] convention.

  • __init__(self, connection: DuckDBPyConnection, relation: str)
  • fetch(self, viewport: Viewport) → list[MapPoint]
  • fetch_at_zoom(self, viewport: Viewport, zoom: int) → list[GridCell] | list[MapPoint]

    Use a world-aligned degree grid below zoom 14 and points at higher zoom.
