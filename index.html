DuckGL

DuckDB spatialの地物を地図に表示し、検索、分析、公開、エクスポートする拡張。

利用ガイドSQL リファレンス

クイックスタート

INSTALL spatial;
INSTALL duckgl FROM community;
LOAD spatial;
LOAD duckgl;
SELECT duckgl_start('127.0.0.1', 8080);

機能ガイド

地図ワークスペーステーブル・地物・属性の表示、座標系の選択、地図とSQLの操作を説明します。エクスポートGeoJSON、CSV、JSON、SVG、PNG、HTML、PDFの用途を確認できます。アプリへの組み込みホストが選んだレイヤーの公開、ビューポート検索、グリッド集約を実行します。サーバー API起動・停止とループバックのレイヤー公開関数を確認できます。
